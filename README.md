## ⚡ Features

- **Authentic Product Showcase**: Comprehensive index of genuine whey proteins, mass gainers, pre-workouts, and health supplements.

## 🛠️ Local Setup & Execution

```bash
# Clone repository
git clone https://github.com/WasimKhan0786/PROTEIN-HUB-NUTRITION.git

# Navigate into project
cd PROTEIN-HUB-NUTRITION

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
